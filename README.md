# Athena Run Club

Website of **Athena Run Club** – a free running community founded and coached by **Esra Kaya**.
Turkish (default) / English.

- `index.html` – public website
- `admin.html` – coach panel (runs, announcements, settings)
- `config.js` – paste the Google Apps Script URL (`ARC_API`) and optional Instagram feed URL (`ARC_IG_FEED`)
- `apps-script/Code.gs` – free backend (Google Sheets)
- `מדריך-התקנה.md` – setup guide (Hebrew)

Live site (GitHub Pages): https://sasi1000e.github.io/athena-run-club/
